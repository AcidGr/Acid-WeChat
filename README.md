# Acid-WeChat

轻量级、基于 **DexKit** 运行时特征定位的 Android 微信 Xposed/LSPosed 增强模块，内置本机多模态 AI Agent 与无版本硬编码偏移的 Hook 体系。

> **架构与开发规范**请参见 [ARCHITECTURE.md](./ARCHITECTURE.md)。

---

## 版本申明与环境适配

| 项目 | 说明 |
| --- | --- |
| **模块版本** | `0.2.0` (`versionCode = 2`) |
| **系统要求** | Android 8.0 及以上（`minSdk = 26`，`targetSdk = 34`） |
| **CPU 架构** | `arm64-v8a`（仅 64 位 ARM） |
| **Hook 框架** | Xposed / **LSPosed**（`xposedminversion = 82`） |
| **LSPosed 作用域** | 勾选 **`com.tencent.mm`**（微信官方包）或 **`com.tencent.mn`**（共存/分身包） |
| **已验证微信版本** | 微信 **`8.0.80` (`3220`)** 全量 55/55 条 DexKit 规则解析通过（其他相近 8.0.x 版本依赖 DexKit 运行时自动适配，具体以首次启动解析日志为准） |

## 已有功能一览

所有功能均可在微信 **「我 → 设置 → 右上角 `Acid`」** 中可视化开关与配置，支持 `config.json` 修改后热重载生效（标注「重启生效」者除外）。

### 1. 聊天增强（`chat`）

| 分组 | 功能名称 | 说明 |
| --- | --- | --- |
| 防止撤回 | **消息防撤回** | 拦截对方撤回消息并保留原内容 |
| 防止撤回 | **撤回本地提示** | 拦截撤回后在聊天内插入本地提示 |
| 防止撤回 | **撤回提示文案** | 自定义本地提示模板，支持 `{name}` 占位符与 `\n` 换行 |
| 动画表情 | **自定义剪刀石头布** | 发送猜拳前弹出 `AcidModal` 选定结果 |
| 动画表情 | **自定义骰子** | 发送骰子前弹出 `AcidModal` 选定点数（1～6） |
| 语音增强 | **自动语音转文字** | 收到他人语音下载完成后自动在后台转写为文字 |
| 语音增强 | **自动展开转写结果** | 转写完成后直接在语音气泡下方展开文字（关闭则仅静默预转写） |
| 语音增强 | **自动去除语音红点** | 自动转写他人语音后标记语音已读，消除未听红点 |
| 语音增强 | **语音通知转文字** | 后台收到他人语音通知时等待短时转写并直接展示文字 |
| 语音增强 | **主页语音转文字** | 微信主页会话列表的语音摘要直接显示转写文字 |
| 语音增强 | **MP3 转语音发送** | 在聊天 **`+`** 面板第二页添加 **`MP3语音`** 按钮（同时支持长按左下角语音图标），拉起系统文件管理器选择本地 MP3/WAV/FLAC/OGG/M4A/AAC/SILK，自动转码为 24kHz SILK v3 并作为微信语音气泡发送（支持微调显示时长 1～60 秒） |
| 输入状态 | **禁止显示正在输入** | 拦截输入状态上报（兼容新旧协议），对方看不到「对方正在输入…」 |

### 2. 本机 AI Agent 助手（`chat` / `home`）

| 能力模块 | 说明 |
| --- | --- |
| **单会话聊天 AI 入口** | 聊天右上角 **`AI`** 按钮，维护独立会话上下文，支持面板私聊与聊天框发送区分、手势/上下文「接管模式」（按钮变绿） |
| **主页全局 AI 入口** | 微信主页右上角 **`AI`** 按钮，支持跨会话查询联系人/聊天记录与代机主发送真实消息 |
| **唤醒自动回复** | 支持群聊 `@` 与自定义唤醒词触发自动回复；外部成员触发时自动进入 `guest` 沙盒隔离模式 |
| **多模态与工具链** | 支持 `wechat`（状态/搜联系人/读消息/发消息）、`sendfile`（发图片/文件/音频转语音气泡）、`readimage`（识图、缩略图按需升级中清图、WXGF 解码）、`drawimage`（文生图/改图）、`websearch`（联网搜索）、`webfetch`（网页抓取）、`read`/`write`/`edit`（沙盒文本读写）、`bash`（仅机主工作区 Shell） |

### 3. 朋友圈增强（`moments`）

| 分组 | 功能名称 | 说明 |
| --- | --- | --- |
| 防删除 | **朋友圈防删除** | 拦截好友删除朋友圈并添加自定义前缀（默认 `❌\n`） |
| 伪集赞 | **朋友圈伪集赞** | 长按朋友圈菜单增加「伪集赞」，支持自选好友或随机指定人数 |
| 伪评论 | **朋友圈伪评论** | 长按朋友圈菜单增加「伪评论」，指定好友与内容添加到本地评论区 |
| 小尾巴 | **朋友圈小尾巴** | 发布朋友圈时附带自定义机型或来源尾巴（支持作为位置来源或正文末尾显示） |

### 4. 我的与系统增强（`me`）

| 分组 | 功能名称 | 说明 |
| --- | --- | --- |
| 保存路径 | **自定义保存路径** | 修改微信保存文件（默认 `Download/AcidWeChat`）与图片视频（默认 `Pictures/AcidWeChat`）的导出目录 |
| 版本保护 | **禁止微信热更新** | 拦截微信 Tinker 热补丁加载并清理补丁目录，防止热更新导致模块失效（重启微信生效） |
| 虚拟定位 | **开启虚拟定位** | 拦截 `TencentLocation` 回调并返回自定义 GCJ-02 经纬度，支持调用微信原生地图选点，覆盖主进程与 `:appbrand*`/`:tools` 子进程 |
| 平板模式 | **强制平板模式** | 伪装平板设备形态并显示「作为其他设备登录」入口（存在风控风险，重启微信生效） |
| 实验开关 | **微信 ABTest / Repairer** | 零 Hook 直读写微信 MMKV 实验配置（内置常用目录，位于设置页内） |
| 系统调试 | **本地调试接口** | 默认监听 `http://127.0.0.1:19898`（可关闭，重启生效），提供 `/health`、`/dexkit`、`/features`、`/config`（`GET`/`POST`）、`/config/schema`、`/config/reset`、`/logs` |

## 数据目录与构建

* **运行时数据目录**（优先外部存储以便查看，不可写时回退到内部私有目录）：
  * `/storage/emulated/0/Android/media/com.tencent.mm/AcidWeChat/`
  * 包含：`config.json`、`config.schema.json`、`agent/models.json`、`workspace/`、`dexkit_cache.json`、`acid.log`
* **构建 Release APK**：
  ```bash
  ./build.sh release
  # 产物：app/build/outputs/apk/release/app-release.apk
  ```
